# Harbor application icon

The mark depicts a harbor entrance: two ivory piers, a connecting bridge and a single turquoise water curve. A deep teal rounded tile gives the app a visible identity in Finder and the Dock without adding text that would disappear at small sizes.

The asset was generated with the built-in image-generation tool, using transparent-background output. The generated square was resized to the standard 1024 × 1024 app-icon source with macOS `sips`; no creative post-processing or third-party API was used. `Resources/AppIcon.png` preserves its alpha channel. Iconset and ICNS packaging is performed by the build workflow.

## Generation prompt

```text
Use case: logo-brand. Asset type: one finished macOS application icon for Harbor (泊岸), a calm native workspace launcher that gives work a place to dock. Generate a single square 1024x1024 icon image, not a mockup or contact sheet. A beautifully proportioned blue-green/deep teal rounded-square tile, centered, occupying 88–90 percent of the canvas, with a genuinely transparent exterior around the tile. Subtle macOS-native dimensional bevel and soft, restrained lighting; clean premium productivity-app aesthetic. Central symbol: a bold simple ivory-white geometric harbor entrance / dock mark, two sturdy upright piers joined by a calm horizontal bridge, suggesting an abstract H as a harbor structure rather than typography. Add one restrained turquoise curved water/shore stroke below the mark. The silhouette must remain immediately legible at 32 pixels. Use broad deliberate shapes, balanced negative space, and minimal detail. No words, no written letters, no numbers, no existing app logos, no thin linework, no border frame, no background scene, no large cast shadows, no extra variants. Preserve real alpha transparency outside the rounded tile; do not draw a checkerboard.
```

## Visual review

One centered icon with a broad, high-contrast mark and a restrained dimensional tile; no text or borrowed app logo. The white piers and turquoise shore remain distinct when reduced. The exterior is transparent. Keep the system menu-bar symbol monochrome; the full-color image is the application icon.
